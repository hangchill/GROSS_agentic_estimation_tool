# Team Contextual Memory (Seed)
 
## Purpose
 
This document seeds **team contextual memory** for the GROSS estimation workflow.
 
It ensures consistent:
- system naming
- acronym usage
- terminology conventions
- architectural phrasing
 
---
 
## Naming Rules
 
- Always use **explicit system names** (e.g. HAS, HH, OAS)
- Never use vague terms like "the system"
- Prefer **canonical acronyms**
- Keep descriptions **capability-level**
  (what it does, not how it is implemented)
 
---
 
## Internal Glossary
 
NN = Nurse Navigator
 
FE = Frontend (User interface logic)
 
BE = Backend (server-side logic)
 
Polys = Polyclinics (HAS-enabled by default)
 
GP = General Practitioner (may be HAS or Non-HAS)
 
NPs = Polyclinics under NUHS or NHG
 
HAS = Health Appointment System (appointment system)
 
Non-HAS = Systems not integrated with HAS
 
HH = HealthHub (national health portal)
 
BAU = Business As Usual
 
MOP = Member of Public
 
SFL = Screen for Life programme
 
NGEMR = National Generic Electronic Medical Record
 
OAS = Outpatient Appointment System
 
HSG = HealthierSG module in HealthHub
 
EISS = Imaging records system
 
PCP = Primary Care Physicians
 
MOH = Ministry of Health
 
NEHR = National Electronic Health Record
 
CHAS = Community Health Assist Scheme
 
NAIS = National Adult Immunisation Schedule
 
CCDP = Common Clinical Data Platform
 
HSGW = Health Services Gateway
 
HSAR = Health Services Application Repository
 
H365 = Health Promotion Board Health 365
 
HHNET = HealthHub Network
 
MyInfo = Government identity/data service
 
OQ = Operational Questionnaire (dynamic logic + validation)
 
HQ = Health Questionnaire
